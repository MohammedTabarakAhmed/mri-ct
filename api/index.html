      🩺 Project Overview

      This Medical AI Diagnosis System is a cutting-edge web application developed as part of our academic project. It leverages advanced deep learning techniques to assist in preliminary medical diagnosis using imaging data.

      🔬 Technical Details

      Brain Tumor Detection: Utilizes a U-Net based convolutional neural network trained on MRI scan datasets to perform semantic segmentation, identifying and highlighting potential tumor regions with high precision.

      Kidney Stone Detection: Employs a ResNet-based classification model to analyze ultrasound and CT images, providing probability scores for stone presence detection.

      ⚠️ Important Disclaimer

      This application is developed for educational and research purposes only. It is not intended to replace professional medical diagnosis or treatment. All results should be verified by qualified healthcare professionals. In case of medical emergencies, please contact your local healthcare provider immediately.

      🛠️ Technologies & Training Details

      Core Technologies:

      • PyTorch: Primary deep learning framework for model development, training, and inference
      • Segmentation Models PyTorch: High-level library providing pre-implemented U-Net architectures with various encoders (ResNet, EfficientNet)
      • torchvision: Computer vision library for image transformations, data loading, and pre-trained model utilities
      • OpenCV: Image processing library for loading, preprocessing, and post-processing medical images
      • NumPy & PIL: Numerical computing and image handling libraries
      • FastAPI: Modern, fast web framework for building REST APIs with automatic OpenAPI documentation
      • Uvicorn: ASGI server for running FastAPI applications
      • Albumentations: Advanced image augmentation library for data preprocessing during training
      • scikit-learn: Machine learning utilities for evaluation metrics and data splitting

      🎯 Model Training Process

      Brain Tumor Segmentation Model:

      • Architecture: U-Net with ResNet-34 encoder (from Segmentation Models PyTorch)
      • Dataset: Medical imaging datasets including TCGA brain MRI scans
      • Training: Binary segmentation task with Dice loss and Adam optimizer
      • Augmentations: Random rotations, flips, brightness/contrast adjustments using Albumentations
      • Validation: Dice coefficient and IoU metrics for segmentation accuracy
      • Hardware: Trained on GPU with CUDA acceleration

      Kidney Stone Classification Model:

      • Architecture: ResNet-50 based classifier with custom fully-connected layers
      • Dataset: Kidney ultrasound and CT scan datasets with stone/normal classifications
      • Training: Cross-entropy loss with Adam optimizer and learning rate scheduling
      • Data Processing: Image resizing to 224x224, normalization, and augmentation
      • Evaluation: Accuracy, precision, recall, and F1-score metrics
      • Hardware: GPU-accelerated training with PyTorch DataLoader for efficient batch processing

      🔧 Development & Deployment

      • Backend: FastAPI with automatic API documentation and CORS support
      • Frontend: Vanilla JavaScript with modern ES6+ features, responsive CSS design
      • Model Serving: PyTorch model loading with GPU/CPU compatibility
      • Image Processing: Real-time preprocessing and post-processing pipelines
      • Error Handling: Comprehensive exception handling and user feedback

      Training Environment: Models were trained on high-performance computing resources with GPU acceleration, utilizing PyTorch's distributed training capabilities for optimal performance.
